Részletes leírás

A program felhasználója és a program sakk-logikája között álló fordító réteg.

A projektben képességeim szerint megpróbáltam a lehető legjobban szétválasztani a UI-t a program többi részétől. Ennek oka az, ha később grafikus megjelenítést szeretnék készíteni a programhoz, akkor magával a logikával nem kell foglalkoznom. Elég megírni ezt a köztes réteget, a grafikus megjelenítést, majd hozzá lehet kötni ugyanazt a kódot.
