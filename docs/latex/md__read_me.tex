Ez a projekt a programozás alapjai 1 tantárgy nagy házifeladatra készült. A projekt egy sakkjáték. A játék a stdin-\/ről lépéseket olvas be, lefordítja, majd a szabályosság ellenőrzése után a stdout -\/ra lerajzolja a lépés utáni sakktábla állását.\hypertarget{md__read_me_autotoc_md2}{}\doxysubsection{\texorpdfstring{Mit tud}{Mit tud}}\label{md__read_me_autotoc_md2}

\begin{DoxyItemize}
\item A program figyel az éppen következő játékosra, kétszer ugyanaz a szín nem léphet.
\item A program figyel a sáncolási szabályokra és a sakkokra. Lépés után nem maradhat sakkban a lépő szín királya.
\item A szabályos lépések betartatásán kívül az átalakulás során meg lehet adni, milyen bábuvá alakuljon át a gyalog. Amennyiben nem volt ilyen megadva, automatikusan vezérré alakul.
\item A játszmát egyszerűen meg lehet szakítani a stdin EOF karakterrel. Windowson ez Crtl + z.
\end{DoxyItemize}\hypertarget{md__read_me_autotoc_md3}{}\doxysubsection{\texorpdfstring{Telepítés és használat}{Telepítés és használat}}\label{md__read_me_autotoc_md3}

\begin{DoxyItemize}
\item A telepítése lehetséges a sakk.\+exe fájl letöltésével és futtatásával.
\item A projekt letöltésével source-\/ból is építhető a projekt, a github oldalról letöltve.
\item A futtatás után az alábbi formátumban lehet a lépéseket megadni: filerowfilerow(optional Q N B R).
\item Például: e2e4 vagy e7e8Q. Ha átváltozásnál nincs megadva bábu, automatikusan vezérré változik a gyalog.
\item Minden lépés után ENTER kell a helyes működéshez
