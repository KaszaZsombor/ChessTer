Ez a projekt a programozás alapjai 1 tantárgy nagy házifeladatra készült. A projekt egy sakkjáték. A játék a stdin-\/ről lépéseket olvas be, lefordítja, majd a szabályosság ellenőrzése után a stdout -\/ra lerajzolja a lépés utáni sakktábla állását.\hypertarget{index_autotoc_md2}{}\doxysubsection{\texorpdfstring{Mit tud:}{Mit tud:}}\label{index_autotoc_md2}

\begin{DoxyItemize}
\item A program figyel az éppen következő játékosra, kétszer ugyanaz a szín nem léphet.
\item A program figyel a sáncolási szabályokra és a sakkokra. Lépés után nem maradhat sakkban a lépő szín királya.
\item A szabályos lépések betartatásán kívül az átalakulás során meg lehet adni, milyen bábuvá alakuljon át a gyalog. Amennyiben nem volt ilyen megadva, automatikusan vezérré alakul.
\item A játszmát egyszerűen meg lehet szakítani a stdin EOF karakterrel. Windowson ez Crtl + z.
